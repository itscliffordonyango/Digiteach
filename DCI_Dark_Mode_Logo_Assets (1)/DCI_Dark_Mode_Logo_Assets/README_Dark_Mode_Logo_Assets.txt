DCI Dark Mode Logo Assets

Source files used:
- Source_DCI_Wordmark_LightMode.pdf
- Source_DCI_Icon_LightMode.pdf

Included assets:
- Transparent SVG wrappers with embedded HD PNG artwork
- Dark-background PDFs for designer review and presentation
- Transparent HD PNGs
- Dark preview PNGs on #0D1930

Dark mode colour logic:
- Background: Deep Indigo #0D1930
- Main text / D frame: Soft Warm Off-White #F4F2EC
- Teal accent: #2AB7A6
- Gold accent: #F2A623
- Orange accent: #E36A35

Note: The SVG files are HD image-based SVGs for predictable visual handoff. They are not fully redrawn vector paths. For final production, a designer may still redraw the marks as native vector paths.
